# A E T H E R | Architectural Bureau

**Минималистичное архитектурное бюро. Архитектура тишины.**

Демонстрационный лендинг для виртуального бюро **A E T H E R**, разработанный в эстетике *«Spatial Brutalism»* meets *«Quiet Luxury»*. Сайт создан как цифровое пространство, напоминающее прогулку по пустому, залитому солнцем музею.

![Aether Preview](https://via.placeholder.com/1200x630/F5F4F0/1C1C1A?text=A+E+T+H+E+R+-+Architecture+of+Silence)

## 🏛 Концепция и Дизайн

Проект реализует философию «Тихой роскоши» через код:
- **Атмосфера:** Монументальная, спокойная, интеллектуальная.
- **Цветовая палитра:** 
  - Фон: `Bone/Alabaster` (#F5F4F0)
  - Текст: `Obsidian` (#1C1C1A)
  - Акцент: `Muted Bronze` (#A38D73)
- **Типографика:** Контраст эмоционального *Playfair Display* (заголовки) и инженерного *Inter* (текст).

## ✨ Ключевые особенности

1. **Immersive Hero Section**: Видео-фон с эффектом параллакса и текстом, появляющимся через маску.
2. **Smooth Scroll**: Интегрирована библиотека Lenis для плавной, инерционной прокрутки.
3. **Micro-interactions**:
   - Магнитный курсор, реагирующий на интерактивные элементы.
   - Эффект «дыхания» типографики при наведении.
   - 3D Tilt эффект на карточках проектов.
4. **Cinematic Animations**: Появление блоков через `clip-path`, горизонтальный скролл внутри вертикального, бегущая строка (marquee).
5. **Film Grain**: Наложение текстуры шума для эффекта печатной страницы.

## 🛠 Технологический стек

- **HTML5** (Семантическая верстка)
- **CSS3** (Custom Properties, Grid/Flexbox, Keyframe Animations)
- **JavaScript (Vanilla)** (ES6+)
- **Lenis** (Для smooth scroll)
- **Google Fonts** (Playfair Display, Inter)

## 🚀 Быстрый старт

### Вариант 1: Локальный запуск
Просто откройте файл `index.html` в любом современном браузере. Сервер не требуется.

```bash
open index.html
```

### Вариант 2: Через локальный сервер (рекомендуется для разработки)
Если у вас установлен Python:
```bash
python3 -m http.server 8000
```
Перейдите по адресу `http://localhost:8000`.

Или через Node.js (npx):
```bash
npx serve .
```
